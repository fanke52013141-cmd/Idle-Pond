# M1 真实感优化方案：让荷塘活过来

> 用户反馈：池塘死气沉沉。没有水波纹路、没有光影、荷叶荷花是死的、缺小鱼小虾螺蛳。
> 本方案目标：从一个"图片池塘"变成"模拟的荷塘"——水在流动，光在移动，生物在呼吸。

---

## 0. 问题诊断

| # | 现状 | 根因 | 目标 |
|---|---|---|---|
| 1 | 水是"画出来的" | 池底图自带波纹和光斑，静态 | 水是模拟的：涟漪、折射、闪光、焦散都实时计算 |
| 2 | 荷叶荷花是死的 | 烘焙在池底图里 | 荷叶/荷花是独立对象：浮动、摆动、开花、有影子、鱼可从下面游过 |
| 3 | 光影不随时间变 | 只有昼/夜两档叠加色 | 太阳按真实时间走轨迹：影子方向/长度、色温、焦散强度全天连续变化 |
| 4 | 生物只有大鱼 | 只做了锦鲤 | 生态群落：小鱼群、虾、螺蛳、蜻蜓、水黾、泡泡、浮萍 |

优先级排序（按"真实感收益/成本"比）：**水面系统 > 荷叶动态 > 昼夜光影 > 生态群落**。前两者是"有没有水"和"有没有生命"的分水岭。

---

## 1. 水面系统（W）

### 1.1 架构：混合渲染

M0 的 Canvas2D 保留为生物绘制层，新增 WebGL2 后处理层把"场景"变成"水下世界"：

```
Canvas2D（场景层，现有代码）：池底 + 影子 + 鱼 + 底栖生物
        ↓ 每帧上传为纹理（texImage2D）
WebGL2 Pass A — 涟漪模拟：高度场 ping-pong（投食/雨/鱼尾/跃水都往里注入扰动）
WebGL2 Pass B — 焦散：从涟漪法线 + 时间噪声生成池底光网，画进场景
WebGL2 Pass C — 水面合成：折射（按法线偏移采样场景）+ 太阳/月亮镜面闪光
        ↓
屏幕（Lively 里就是壁纸）
```

降级路径：无 WebGL2 时保持 M0 现状（Canvas2D 涟漪圈已有），功能开关记录在性能分档里。

### 1.2 要做的效果清单

| 效果 | 触发 | 实现 |
|---|---|---|
| **折射水纹**（基础，"真实水"的来源） | 常驻 | 涟漪高度场 + 微风基线波浪合成法线，场景纹理按法线偏移采样；静态池底图换成无波纹版，波纹全部由shader生成 |
| **闪光/波光** | 太阳/月亮方向 | 法线朝向光源的像素加镜面高光；金色时刻偏暖、正午偏白、月光偏冷银 |
| **焦散光网** | 常驻，强度随太阳高度 | 光网打在池底和鱼背上（鱼贴图上叠加），阴天/夜晚消退 |
| **鱼尾迹** | 鱼贴近水面快速游动 | 每隔 ~0.15s 在鱼头位置注入一次小扰动（原作验证过的参数） |
| **投食水花** | 点击投喂 | 涟漪圈 + 3-5 颗水珠粒子抛物线弹出，落水二次涟漪 |
| **鱼跃出水面** | 随机事件（进食后/清晨活跃期概率触发） | 完整编排：加速上浮 → 破水（身体露出部分叠加高光+水珠拖尾）→ 空中弧线 → 入水水花冠 + 涟漪 + 溅落荷叶的水珠 | 
| **水珠落荷叶** | 鱼跃/雨滴 | 水珠精灵落在叶面：滚动、合并变大、滚出叶缘掉回水里触发小涟漪 |

### 1.3 池底图重新生成

当前这张图自带波纹/光斑/荷叶，会与实时水面冲突。用 toapis 重新生成：**纯水底**（细沙+卵石+矿物纹理，无波纹、无光斑、无荷叶荷花，中心 80% 干净水域）。荷叶荷花改为程序化对象（见 §2）。1K/low 即可，同提示词风格只删要素。

## 2. 植物系统（P）：荷叶与荷花活起来

### 2.1 荷叶从"背景"变"对象"

- **程序化荷叶**（Canvas2D 绘制，同锦鲤的做法）：径向叶脉、缺口、边缘微卷（用明暗表现杯状）、防水叶面的高光、随机大小 4-6 档。生成 3-4 个变体缓存。
- **布局**：初始 6-10 片，聚在角落和边缘（参考原作的分布逻辑），留出中央水域。
- **浮动**：采样自身位置处的涟漪高度，叶片上下浮动 + 随波倾斜（叶心偏移几像素，投影同步变形）。
- **随风**：整体缓慢漂移 + 微旋转；风越大漂得越快（风参数与水面波浪共用）。
- **荷叶的影子**：每片叶在水面/池底投下影子，偏移量随太阳方位变化（§3）。这是"光影随时间变"最直观的载体。
- **叶下可以游鱼**：绘制层级——鱼 < 荷叶影子 < 池底焦散 < 荷叶本体。鱼从叶下游过时被叶片遮挡，AI 上把荷叶标记为**遮荫区**：正午高温时段鱼偏好待在叶下（目标点偏好），清晨傍晚出来巡游。喂养时食物落在叶缘，鱼会探出头吃。
- **生长**：新叶从"卷曲小叶"展开（scale + 形状插值，约 2-3 天真实时间长成）；荷叶密度上限，最老的叶慢慢枯黄（色相偏移 + 边缘焦褐）。

### 2.2 荷花：摆动、开合、绽放

- 花瓣分层绘制（8-12 瓣独立角度），支持两个自由度：整花随风点头 + 花瓣开合角。
- **昼夜开合**：真实荷花晨开午合——清晨全开，午后渐合，夜里闭合；开放度是连续动画而非开关。
- **绽放事件**：花苞期 → 绽放（约 1 个游戏日内完成，展开过程用花瓣角插值 + 淡入花色）；凋谢后留莲蓬（另一个精灵）。
- **季节物候**（§3.3）：夏盛花、秋残叶、冬枯梗——由系统日期驱动。

## 3. 昼夜与季节光影（L）

### 3.1 太阳轨迹（连续，不是档位）

用本地时钟（中国用户即北京时间）计算太阳高度角/方位角，全 天连续插值，不再有"昼/夜"跳变：

```
sunElevation(t) = sin 曲线，日出≈5:30（夏）/7:00（冬）到正午最高
sunAzimuth(t)   = 东（晨）→ 南（午）→ 西（昏）
shadowDir       = -sunAzimuth（影子永远背向太阳）
shadowLength    ∝ 1 / tan(sunElevation)（晨昏长、正午短，做上下限钳制）
```

驱动的参数：影子方向与长度（鱼/荷叶/生物全部生效）、水色色温（晨昏暖金 → 正午清白 → 夜冷蓝）、焦散与闪光强度/颜色、环境亮度、薄雾（清晨一层轻雾）、萤火虫（夜晚）、月光（夜晚按月相给不同满月/弯月贴图，加分项）。

### 3.2 一天中的关键时刻（设计目标）

| 时刻 | 画面 |
|---|---|
| 5:30-7:00 日出 | 薄雾、长影、金色水面、荷花绽放中、鸟鸣（音频后期） |
| 正午 | 短影、强焦散、鱼躲叶荫、闪光最亮 |
| 17:30-19:30 黄金时刻 | 暖金长影、逆光波光、鱼活跃 |
| 夜 | 月光洒水、萤火虫、荷花闭合、蛙鸣（后期） |

### 3.3 季节（按系统日期）

- 春：小卷叶、新荷、鱼活跃
- 夏：荷叶最盛、花开最多、蜻蜓
- 秋：叶缘枯黄、花少、落叶飘落水面（floater）
- 冬：枯梗残叶、水面偶尔结冰纹（北极光滤镜慎用，做淡蓝灰调即可）

季节通过 looks 数据表扩展实现（方案 B7 的延续），不改逻辑。

## 4. 生态群落（E）：真实荷塘的生物清单

按真实荷塘盘点，按"收益/成本"分三档：

### 第一档（本期必做）

| 生物 | 行为 | 实现要点 |
|---|---|---|
| **小鱼群**（餐条/鲫鱼苗） | 15-25 尾紧密群游；锦鲤冲刺时炸群四散，几秒后重新聚拢；抢食碎屑 | 轻量 boids（聚合/对齐/分离三个力）+ 惊吓力场；单尾 8-12px，银色闪光贴图（程序化，1 个变体+色调抖动） |
| **水黾** | 在水面滑行，腿下压出小凹坑涟漪；被惊时连续弹跳逃走 | 生活在"水面层"（不受折射影响的位置语义）；移动时周期性注入微涟漪——**水面系统最好的展示者** |
| **泡泡** | 深水鱼/底栖生物呼吸的气泡上浮，到水面破裂出微涟漪 | 粒子+到达水面时注入小扰动 |
| **浮萍** | 细小绿点随波漂，聚在静水角；锦鲤会啄食（小零嘴） | floater 粒子池 + 涟漪场轻微推动 |

### 第二档（本期做 2 个）

| 生物 | 行为 | 备注 |
|---|---|---|
| **螺蛳** | 贴底极慢爬行（随机路径+转身），偶尔爬上荷叶梗 | 纯装饰但"真实感"贡献大；也响应焦散光照 |
| **青虾** | 底栖半透明，弹跳式后退移动；有食物时围拢 | 与小鱼群共用群游逻辑的变体 |

### 第三档（M2 及以后）

- **蜻蜓**：空中悬停、点水产卵（触发涟漪）、落荷尖
- **青蛙**：蹲荷叶上，黄昏鸣叫（喉囊动画+音效），受惊入水
- **翠鸟/白鹭掠影**：影子扫过+鱼群躲避（稀客彩蛋，纯影子零贴图成本）

**尺寸修正**：锦鲤整体 size 下调 ~15%，拉开与小鱼的体型差，群落层次立刻出来。

## 5. 工程改动总览

```
src/
  core/    + sun.ts（太阳轨迹）、minnow.ts（boids）、plants.ts（荷叶/荷花状态机）
  art/     + lily.ts（荷叶/荷花/莲蓬程序化贴图）、critters.ts（小鱼/虾/螺/水黾/水珠/泡泡）
  render/  + gl/（WebGL2：ripple sim、water composite、caustics）
           pond2d.ts 保留为场景层与降级路径
  app/     时钟驱动 look 参数（每帧插值），事件调度（鱼跃/蜻蜓点水/掉露）
assets/    pond.jpg 重生成（无波纹无荷叶版）
```

性能预算不变：包 ≤ 2MB（新增全为代码，预计 +40KB）；核显 1080p 稳 60fps（涟漪模拟用 1/4 分辨率高度场，焦散 1/2 分辨率，均验证过的原作参数区间）；无 WebGL2 时自动回退 M0 画质并提示。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| Canvas2D 纹理上传开销（每帧 texImage2D） | 1080p 下实测通常 <1.5ms；不行则生物层迁为 WebGL 四边形绘制（原作路线），保留 2D 仅做贴图生成 |
| 程序化荷叶/荷花美感不达标（同 M0 鱼的风险） | 小步迭代 + 截图对比；荷叶先做单色块验证形/影/浮动，再补叶脉细节 |
| 生物数量上去后帧率 | 所有粒子/生物走限量池；小鱼群用一张共享贴图批量绘制；eco 档降生物数量与涟漪分辨率 |
| 范围膨胀 | 严格按档位推进，第三档生物本期不做 |
