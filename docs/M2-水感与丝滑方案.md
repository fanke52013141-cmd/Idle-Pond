# M2 方案：水感、丝滑、生物美化（含反思）

> 触发：用户反馈"水没有波纹/不流动、小动物丑、运动不丝滑、完成度低"。
> 本文承认根因、给出已修复的证据，并列出达到原作观感的完整任务清单与量化验收标准。

---

## 一、反思：三个真实错误

### 1. 涟漪模拟从未运行过（最严重）

数值实锤（readPixels 直接读模拟纹理）：

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 注入 strength=0.12 后高度场最大值 | 0.5（=清屏色，纹丝未动） | 0.1136 ✓ |
| 法线 XY 最大值 | **0（完全平坦）** | 1.0（可见） |
| 折射位移 | **0 px** | ~12 px |
| 扩散 30 步后 | 0.5（不变） | 0.0245（阻尼衰减 ✓） |

三个叠加的 bug：
- **shader 模板变量错误**：sim/drop 着色器输出写成"输入原值"（`t.r`/`t.g`），而不是计算出的
  `h`/`v` —— 模拟每帧把纹理原样拷贝一遍，等于没跑；
- **float 模式清屏色错误**：高度零点应是 0，被清成 0.5（RGBA8 编码才用 0.5）；
- **斜率量级未标定**：高度差相对 UV 步长只有 ~1e-2，法线不放大则折射 <0.5px，肉眼不可见。
  修复：法线 pass 增加 `uSlope` 增益（当前 22），焦散改为法线散度（会聚增亮，物理正确且量级匹配）。

**更深的过程错误**：我此前用"注入水滴前后像素有变化"验收折射——那是噪声微波滚动造成的**假阳性**，
被我误读为涟漪生效。教训写进验收规范：**效果验收必须直接测量模拟场本身**（读回高度/法线），
不能只看最终像素差。

### 2. 小动物手绘矢量是错误的成本决策

荷叶/荷花/池底都走了 AI 生成且效果已验证，小鱼/虾/螺/水黾却手绘矢量——不是能力问题，是偷懒。
"丑"的评价成立。M2 全部 AI 化（见 §C）。

### 3. "丝滑"从未进入验收指标

三笔具体的性能债（Chromium 实测慢路径）：
- 每片荷叶**每帧** `ctx.filter`（brightness/saturate）——13 片 × 60fps，Canvas filter 是著名慢路径；
- 小鱼绘制**每帧每条** `createLinearGradient`——18 条 × 60fps；
- 帧循环的 `interval*0.8` 节流阈值导致**帧间隔抖动**（pacing 不均，主观就是"不丝滑"）。

## 二、任务清单

### Phase W 水感（对标原作水面四层结构）

原作的水 = 涟漪模拟 + **预计算波纹法线图（流动感的真正来源，waveData）** + 焦散 + 碎金波光。
我们目前只有 1、3 的弱化版。

| # | 任务 | 做法 | 验收 |
|---|---|---|---|
| W1 | 涟漪修复 | ✅ 已完成（本文件 §一） | 已过（数值+截图） |
| W2 | 流动感：方向性波纹法线图 | JS 预合成 3-4 个方向正弦波的**可平铺法线图**（256²，非当前的 value-noise RGB 近似），两图层反向滚动，滚动方向受风场偏置 → 水在"流"而不只"闪" | 盲看 10s 视频：水面有明确流向感；风改变时流向跟随 |
| W3 | 碎金波光层 | 独立 glint 计算：噪声阈值化的高光斑点（两层尺度+时间抖动），乘太阳色温；夜里换成月光银碎 | 白天截图出现星点状闪烁（非当前的大面积镜面） |
| W4 | 水色分级 | 深浅水域吸收色（边缘浅、中心深，径向渐变叠加）+ 低权重天空反射项 | 水有"厚度"感，中心比边缘深一档 |
| W5 | 雨模式 | 雨滴 streak 精子 + 密集小 drop 注入 + 叶面聚珠（模拟已 ready，纯接线） | 雨天：水面持续细密涟漪 |
| W6 | 交互强化 | 投食=3 圈递扩涟漪+水花；鱼跃入水=大涟漪+冠 | 手感"有水" |

### Phase S 丝滑

| # | 任务 | 做法 | 验收 |
|---|---|---|---|
| S1 | 帧循环重构 | 删除 `interval*0.8` 节流；rAF 直驱 + dt clamp(50ms)；eco 档改"隔帧渲染"而非时间阈值 | 帧间隔直方图均匀，无 >25ms 尖峰（正常负载） |
| S2 | 消灭每帧 ctx.filter | 荷叶按亮度桶（0.05 步长）预渲染着色缓存，运行时纯 drawImage | Performance 面板零 filter 记录 |
| S3 | 小鱼批量化 | 精子图集 + 单次 drawImage 循环；删除每帧渐变创建 | 帧耗时下降（数值对比） |
| S4 | 自适应画质 | 连续 2s 帧均值 >12ms → scene DPR 降档（2→1.5→1.25），恢复升回 | 低配机不掉帧、不糊 |
| S5 | 动画平滑 | 小鱼转向角插值（消除折角）、锦鲤深度变化限速、水黾轨迹平滑 | 无肉眼折角/跳变 |

## 三、总验收门（量化）

1. **水**：交互涟漪圈肉眼可见、扩散 ≥2s；流向感/碎金/水色四层齐备；盲测 10s 视频被判断"像真的水"
2. **丝滑**：主线程帧耗时 p95 < 8ms（软件渲染）/ < 4ms（GPU）；零每帧 filter/gradient 分配
3. **生物**：与荷叶同框截图"看不出程序绘制"
4. **回归**：清晰度指标 ≥ 7.8 不回退；包 ≤ 2MB；tsc 零错误

## 四、执行顺序

W2 → W3 → S1 → S2 → S3 → C1-C5 → W4/W5 → W6 → 总验收 → 推送仓库
